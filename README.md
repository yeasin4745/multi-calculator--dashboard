### Clone & Run Locally

```bash

git clone https://github.com/yeasin4745/multi-calculator--dashboard.git

# Navigate to the project
cd multi-calculator--dashboard

# Open index.html in your browser
open index.html
# OR on Windows:
start index.html
# OR on Linux:
xdg-open index.html
```

That's it! No installation, no dependencies, just open and use.

## 🎯 How to Use

### Simple Calculator

1. Click number buttons (0-9)
2. Click operator buttons (+, -, *, /)
3. Press **=** to calculate
4. Use **C** to clear
5. Use **MS**, **MR**, **MC** for memory

**Keyboard Shortcuts:**
- `0-9` - Numbers
- `+ - * /` - Operators
- `.` - Decimal
- `Enter` - Equals
- `Escape` - Clear
- `Backspace` - Delete last character

### Other Calculators

1. Select a calculator from the tabs
2. Enter the required values
3. Click **Calculate** button
4. View the result instantly
5. Check history for previous calculations
