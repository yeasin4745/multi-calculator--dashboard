# Multi-Calculator Dashboard

## প্রজেক্ট সম্পর্কে | About the Project

এটি একটি **মাল্টি-ক্যালকুলেটর ড্যাশবোর্ড** যাতে ৬টি ভিন্ন ধরনের ক্যালকুলেটর রয়েছে। যেকোনো একটি ট্যাব নির্বাচন করে সহজেই গণনা করা যাবে।

This is a **Multi-Calculator Dashboard** with 6 different calculators in one place. Simply select a tab and perform your calculations.

---

## বৈশিষ্ট্যসমূহ | Features

### ১. সাধারন ক্যালকুলেটর | Simple Calculator
- মৌলিক গণিত: যোগ, বিয়োগ, গুণ, ভাগ (+, -, *, /)
- ব্র্যাকেট ব্যবহার করা যায় ( )
- দশমিক সংখ্যা সমর্থন
- মেমরি ফাংশন: MS (সংরক্ষণ), MR (আনা), MC (মুছে ফেলা)
- কীবোর্ড সমর্থন
- গণনার ইতিহাস

Basic arithmetic: addition, subtraction, multiplication, division
- Parentheses support
- Decimal numbers
- Memory functions: MS (Store), MR (Recall), MC (Clear)
- Keyboard support
- Calculation history

### ২. বয়স ক্যালকুলেটর | Age Calculator
- জন্ম তারিখ থেকে বয়স গণনা
- বছর, মাস, দিন, ঘন্টা, মিনিট, সেকেন্ডে বয়স দেখায়
- পরবর্তী জন্মদিনের কাউন্টডাউন
- পরবর্তী জন্মদিনের তারিখ
- গণনার ইতিহাস

Calculate age from date of birth
- Shows age in years, months, days, hours, minutes, seconds
- Countdown to next birthday
- Next birthday date
- Calculation history

### ৩. BMI ক্যালকুলেটর | BMI Calculator
- ওজন (কেজি) এবং উচ্চতা (সেমি) থেকে BMI গণনা
- BMI ক্যাটেগরি: কম ওজন, স্বাভাবিক, অতিরিক্ত ওজন, স্থুলতা
- ভিজ্যুয়াল প্রগ্রেস বার
- রং কোডেড ফলাফল
- গণনার ইতিহাস

Calculate BMI from weight (kg) and height (cm)
- BMI categories: Underweight, Normal, Overweight, Obese
- Visual progress bar
- Color-coded results
- Calculation history

### ৪. মুদ্রা রূপান্তরকারী | Currency Converter
- ১০টি মুদ্রা সমর্থন: USD, EUR, GBP, JPY, AUD, CAD, INR, BDT, PKR, SGD
- প্রি-লোডেড এক্সচেঞ্জ রেট
- কাস্টম রেট ব্যবহার করা যায়
- মুদ্রা সোয়াপ করা যায়
- রূপান্তরের ইতিহাস

Supports 10+ currencies: USD, EUR, GBP, JPY, AUD, CAD, INR, BDT, PKR, SGD
- Pre-loaded exchange rates
- Custom rate override
- Swap currencies
- Conversion history

### ৫. ঋণ ক্যালকুলেটর | Loan Calculator
- ঋণের পরিমাণ, সুদের হার, মেয়াদ ইনপুট
- মাসিক কিস্তি গণনা
- মোট পরিশোধ এবং মোট সুদ
- কিস্তির সংখ্যা
- গণনার ইতিহাস

Loan amount, interest rate, term inputs
- Monthly payment calculation
- Total payment and total interest
- Number of payments
- Calculation history

### ৬. ইউনিট রূপান্তরকারী | Unit Converter
- **দৈর্ঘ্য**: মিটার, কিলোমিটার, সেন্টিমিটার, মিলিমিটার, ইঞ্চি, ফুট, গজ, মাইল
- **ওজন**: কিলোগ্রাম, গ্রাম, মিলিগ্রাম, পাউন্ড, আউন্স, টন
- **তাপমাত্রা**: সেলসিয়াস, ফারেনহাইট, কেলভিন
- **এলাকা**: বর্গ মিটার, বর্গ কিলোমিটার, বর্গ সেন্টিমিটার, বর্গ ফুট, বর্গ ইঞ্চি, একর, হেক্টর
- **আয়তন**: লিটার, মিলিলিটার, ঘন মিটার, গ্যালন, কোয়ার্ট, পিন্ট
- **গতি**: মিটার/সেকেন্ড, কিলোমিটার/ঘন্টা, মাইল/ঘন্টা, ফুট/সেকেন্ড, নট

- **Length**: Meter, Kilometer, Centimeter, Millimeter, Inch, Foot, Yard, Mile
- **Weight**: Kilogram, Gram, Milligram, Pound, Ounce, Ton
- **Temperature**: Celsius, Fahrenheit, Kelvin
- **Area**: Square Meter, Square Kilometer, Square Centimeter, Square Foot, Square Inch, Acre, Hectare
- **Volume**: Liter, Milliliter, Cubic Meter, Gallon, Quart, Pint
- **Speed**: Meter/second, Kilometer/hour, Mile/hour, Foot/second, Knot

## কিভাবে ব্যবহার করবেন | How to Use

### ওয়েব ব্রাউজারে ওপেন করা | Open in Browser
1. `index.html` ফাইলটি কোনো ওয়েব ব্রাউজারে ওপেন করুন
2. ট্যাব থেকে প্রয়োজনীয় ক্যালকুলেটর নির্বাচন করুন
3. ইনপুট ফিল্ডে মান লিখুন
4. ক্যালকুলেট বাটনে ক্লিক করুন
5. ফলাফল দেখুন

1. Open `index.html` file in any web browser
2. Select the calculator you need from the tabs
3. Enter values in the input fields
4. Click the Calculate button
5. View the result

### কীবোর্ড ব্যবহার | Keyboard Usage (Simple Calculator)
- সংখ্যা: `0-9`
- অপারেটর: `+`, `-`, `*`, `/`
- ইকুয়াল: `Enter` বা `=`
- ক্লিয়ার: `Escape`
- ব্যাকস্পেস: `Backspace`

- Numbers: `0-9`
- Operators: `+`, `-`, `*`, `/`
- Equal: `Enter` or `=`
- Clear: `Escape`
- Backspace: `Backspace`
